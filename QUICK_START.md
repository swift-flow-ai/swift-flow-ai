## Project Structure
```
src/
├── pages/          # LoginPage, SignupPage, DashboardPage
├── components/     # Button, Input, Card, AppLayout
├── contexts/       # AuthContext (authentication)
├── services/       # API client & auth service
├── hooks/          # useAuth
├── types/          # TypeScript types
└── utils/          # Helper functions
```
